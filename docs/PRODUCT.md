# TechPilot — Référence produit

## Positionnement

TechPilot est un SaaS B2B vertical pour les professionnels de l'électronique.

Il couvre progressivement :
- gestion de l'entreprise ;
- utilisateurs, employés et rôles ;
- clients ;
- appareils ;
- stock ;
- ventes ;
- facturation et paiements ;
- diagnostics ;
- tests de performance ;
- batterie ;
- thermique ;
- réparation ;
- reconditionnement ;
- certification ;
- rapports ;
- firmware via méthodes légitimes ;
- récupération de données lorsque techniquement possible ;
- automatisations ;
- assistant IA ;
- statistiques ;
- notifications ;
- intégration avec TrouveTout.

## Utilisateur cible

Un professionnel peut gérer une ou plusieurs activités, avec des employés et des rôles. Une boutique et un atelier ne constituent pas deux types de comptes distincts : ils peuvent appartenir au même compte professionnel / tenant.

## Parcours cible

1. Ajouter ou connecter un appareil.
2. Détecter et identifier l'appareil.
3. Collecter les caractéristiques disponibles.
4. Exécuter les tests compatibles.
5. Analyser les résultats.
6. Calculer les scores.
7. Générer un rapport.
8. Certifier lorsque les conditions sont remplies.
9. Ajouter ou mettre à jour le stock.
10. Vendre ou publier.
11. Conserver l'historique.
12. Refaire un diagnostic ultérieurement.

## Évaluation

Les résultats doivent être compréhensibles et contextualisés.

Profils d'usage prévus :
- usage quotidien ;
- réseaux sociaux ;
- vidéo ;
- photographie ;
- travail ;
- GPS ;
- jeu léger ;
- jeu intensif ;
- batterie ;
- stabilité thermique.

Un appareil doit être évalué selon sa catégorie et sa génération, sans transformer une bonne performance relative en score absolu trompeur.

## Certification

Une certification peut contenir :
- identifiant unique ;
- appareil ;
- professionnel ;
- date ;
- résultats ;
- scores ;
- statut ;
- QR code ;
- URL publique de vérification ;
- mécanisme d'intégrité approprié.

Une certification décrit l'état de l'appareil au moment du diagnostic.

## TrouveTout

TechPilot et TrouveTout restent deux produits distincts.

TechPilot peut publier ou synchroniser certaines données vers TrouveTout via une intégration contrôlée.

Flux cible :

**Professionnel → TechPilot → Certification / Stock → Publication optionnelle → TrouveTout → Acheteur**

## Limites techniques

Le produit doit représenter explicitement les limites :
- appareil totalement inerte ;
- absence de communication USB ;
- matériel inaccessible ;
- tests nécessitant une application compagnon ;
- dommages physiques ;
- récupération de données impossible ou partielle ;
- firmware dépendant du modèle, de la variante ou de la région.

Aucune donnée indisponible ne doit être inventée.
