# TechPilot — Feuille de route

Cette feuille de route est une référence initiale. Les priorités peuvent être ajustées après audit technique et validation produit.

## Phase 0 — Fondation

- audit du dépôt ;
- choix/validation de la stack ;
- architecture ;
- modèle de données ;
- règles de développement ;
- sécurité ;
- CI/CD ;
- observabilité de base.

## Phase 1 — SaaS professionnel

- authentification ;
- entreprise / tenant ;
- utilisateurs ;
- rôles et permissions ;
- clients ;
- appareils ;
- stock ;
- tableau de bord.

## Phase 2 — Diagnostic initial

- identification appareil ;
- caractéristiques ;
- tests compatibles ;
- résultats ;
- scoring ;
- analyse ;
- rapport.

## Phase 3 — Certification

- certificats ;
- QR code ;
- vérification publique ;
- intégrité ;
- historique.

## Phase 4 — Commerce

- stock avancé ;
- ventes ;
- factures ;
- paiements ;
- suivi client ;
- publication.

## Phase 5 — TrouveTout

- couche d'intégration ;
- synchronisation ;
- publication contrôlée ;
- retour d'état.

## Phase 6 — Réparation

- dossiers de réparation ;
- diagnostic avant/après ;
- pièces ;
- main-d'œuvre ;
- statuts ;
- historique.

## Phase 7 — Fonctions techniques avancées

- firmware via méthodes légitimes ;
- récupération de données lorsque techniquement possible ;
- outils spécialisés ;
- workflows techniques.

## Phase 8 — Automatisation et IA avancées

- assistant professionnel ;
- génération de rapports ;
- automatisations ;
- recommandations ;
- agents spécialisés ;
- orchestration de workflows.

## Phase 9 — Extension

- API B2B ;
- multi-sites ;
- statistiques avancées ;
- nouveaux types d'appareils ;
- intégrations supplémentaires.

## Règle de progression

Une phase ne doit pas être considérée comme terminée uniquement parce que le code existe.

Chaque phase doit disposer de :
- tests ;
- validation fonctionnelle ;
- sécurité vérifiée ;
- documentation ;
- observabilité suffisante ;
- procédure de déploiement ;
- critères d'acceptation.
